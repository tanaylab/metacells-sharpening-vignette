# The tool chain which generates the documents, pinned so that running `make docs` locally produces
# what the CI server produces. An unpinned dependency is enough to change the result: one version of
# `pygments` renders a cell magic as one token and the next renders it as two, and the generated
# bytes are what the CI server compares.
#
# This is *not* what the vignette itself needs. Those eight packages are installed by
# `metacells-sharpening-setup-environment.sh`, from the head of each repository, and none of them is
# here: generating the documents converts a notebook which was executed elsewhere, so it needs
# neither the packages nor the Julia they talk to nor the input data. `make run` is the one target
# which needs the vignette's own environment, and it is not the one this file is for.
#
# To upgrade, regenerate with `pip freeze` in an empty virtual environment holding only
# `nbconvert[webpdf]` and `ipython`, taking care that `PYTHONPATH` is not set, and regenerate the
# documents in the same commit.
#
# `playwright` is here because a PDF is printed from the HTML by a headless chromium, which it
# provides; `playwright install --with-deps chromium` fetches the browser itself, which is not a
# Python package and so cannot be pinned here. IPython is here for its lexer: without it the
# highlighting of a cell magic such as `%%time` falls back to plain Python.
