# Metacells Sharpening Vignette

Sharpening takes metacells computed by something else — an MC2, `scvi` or SEACells partition — and improves them, using
the `Metacells.jl` pipeline. This is a Jupyter notebook which runs that pipeline on a gastrulation dataset, in Python,
through `metacellspy`.

## Running it

See [INSTALL.md](INSTALL.md). It describes two ways of installing — into the Python and Julia you already use, or into
a conda environment which brings its own — and which to choose. Eight packages are involved, three Python and five
Julia, and no package index carries a working version of any of them, which is why installing is a document of its own.

The notebook reads three files from `input/`, which are not in this repository, being far too large for one.

## The build

The documents are generated by `make`, which describes itself:

```
make help
```

`make docs` generates the HTML and the PDF from the committed notebook. `make ci` also checks them, and is what the CI
server runs, so running it locally does exactly what happens there.

Executing the notebook is `make run`, and is separate because it runs the whole pipeline. Even then, only a notebook
whose *code* changed is executed: the fingerprint of the code cells is recorded in the notebook itself, so rewording a
paragraph regenerates the documents without recomputing anything. Executing is done in place, so the outputs are
replaced while the prose around them stays as it is.

Only `make run` needs the vignette's own environment. Generating the documents is a separate tool chain, pinned in
`requirements.txt`, and needs neither the eight packages nor the Julia they talk to nor the input data — the notebook
is committed with its outputs, and converting it is all that happens. `EXECUTE_IN` is how the vignette's environment is
entered, and defaults to the conda install:

```
make run                  # the conda environment
make run EXECUTE_IN=      # the Python and Julia you already use
```
